# 演示与验收

## 六分钟演示脚本

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00～0:40 | 驾驶总览，正常导航，开始/暂停 | 系统五个模块、模拟数据、统一时钟、非真实车控 |
| 0:40～1:30 | 路径推荐，比较三张卡，应用偏好 | 同一 Dijkstra 在不同目标函数下的路线差异 |
| 1:30～2:15 | 恢复距离优先，运行中央街拥堵/封路 | 路况如何改变边代价及可达性；途中重规划不跳位置 |
| 2:15～3:15 | 前车急停 · 侧方占用，再运行可换道场景 | 状态机、拒绝换道的理由、制动与避让的区别 |
| 3:15～4:00 | 传感器中断，观察降级，再点恢复 | 观测时效、故障优先级、恢复路径 |
| 4:00～4:45 | 用户行为，切换频繁加减速样本 | 规则、阈值、采样点统计、合成数据来源 |
| 4:45～5:30 | 实验记录、历史摘要、CSV 导出 | 事件证据与可解释性；历史摘要不是完整轨迹回放 |
| 5:30～6:00 | 展示架构和当前边界 | 已完成模块、测试、SUMO 后续接入计划 |

## 手工验收清单

- [ ] 启动后页面显示“本地服务已连接”，浏览器控制台无未捕获异常。
- [ ] 正常导航最终到达 D；暂停期间仿真时间和车辆位置不变。
- [ ] 三种偏好在正常路网下分别选择中央商业街、城市快速路和绿荫大道。
- [ ] 距离优先下中央街拥堵后路线改变；封闭的 BC 不在推荐路线中。
- [ ] 在 AB 行驶途中封闭 BC，车辆坐标不跳回起点，后续改道。
- [ ] 急停且侧方占用时不换道，车速归零，前方净间距大于零，碰撞数为零。
- [ ] 可换道场景中车道由 0 变成 1，换道完成事件出现，车辆继续行驶。
- [ ] 传感器中断超过 0.5 仿真秒后降级并停车；恢复后继续。
- [ ] 全部出口封闭时显示无可行路线；恢复 BC 后能够重新行驶。
- [ ] 同一行为样本重复分析结果一致；频繁加减速样本能出现异常采样点。
- [ ] 记录页有实验摘要；导出的 CSV 能读取中文。
- [ ] 关闭服务并重启，历史事件仍在；新实验从初始场景开始。

## 自动化检查

```powershell
python -m unittest discover -s tests -v
```

覆盖路线目标差异、闭路、拥堵、途中改道、无路恢复、终点判定、制动、换道、传感器时效、暂停、重置、JSON 可序列化、SQLite 持久化、SUMO XML 引用和 HTTP 接口。

可选浏览器脚本 `tools/browser_smoke.mjs` 验证主页面、偏好切换、行为分析、急停/避让/传感器恢复、日志和移动端布局。测试结束会将实验重置并暂停；不要在正式演示中同时运行此脚本。

## 指标的实际含义

| 指标 | 当前计算方式 | 不能据此推断 |
|---|---|---|
| 预计通行时间 | 路段长度/设定速度×拥堵系数求和 | 包含交通灯、制动和停车等待的真实 ETA |
| 最小间距 | 同路段同车道固定障碍的已观测纵向净间距最小值 | 全场景、所有车辆的预测碰撞风险 |
| 减速度峰值 | 离散速度差分的最大负值 | 真实车辆制动系统极限 |
| 碰撞标记 | 简化纵向重叠判断 | 已通过完整车身包络或实车安全验证 |
| 用户行为评分 | 合成样本的规则计分 | 经真实人群标注验证的模型准确率 |

建议比较时保存同一场景、同一偏好和相同初始条件。倍速只改变演示推进速度，仿真固定步长不变。

## 断电或现场故障处理

1. 保留 `data/driverlab.sqlite3`，不要为了重启删除数据库。
2. 重新执行 `python server.py`，等待启动地址出现后刷新页面。
3. 端口冲突时改用 `--port 8001`，并同步修改浏览器地址。
4. 如果浏览器显示旧状态，先确认服务在运行；页面会在连接中断时给出提示。
5. 使用已有截图和录制视频作为演示备份，但清楚说明是已录制结果。
